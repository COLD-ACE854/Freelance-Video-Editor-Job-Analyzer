# Video Editing Job Analyzer

Analyze freelance video editing job posts and estimate whether to Accept, Negotiate, or Reject based on workload, pay, risk, and deadlines.

## What it does

Paste a job description and receive:

* Estimated workload
* Effective hourly rate
* Risk assessment
* Accept / Negotiate / Reject recommendation

## Why

Freelance editors often underestimate revision requests, hidden work, deadlines, and approval chains.

This tool helps estimate the true value of a project before accepting it.
